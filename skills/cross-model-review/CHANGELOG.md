- **v1.1.2 (2026-09-26 修正、09-27 codex 互審 3 輪 APPROVED，reviewer=codex:gpt-6-astra@high，Gate 4 FAIL=0 WARN=0)**: 起因：Step 6 歸檔行 `cp "$DIR"/r*.txt … && cp "$DIR"/*REPORT*.md … 2>/dev/null` 的裸 glob 在 zsh 遇無匹配 nomatch 中斷整行——黃 tier 無 signoff／REPORT 未產出時 exit=1、歸檔不完整→hook fail-closed 卡死（bash 不受影響：cp 收字面 pattern 安靜失敗、正是原行 2>/dev/null 的預期）→ 改 `find -maxdepth 1 \( -name … \) -exec cp`，四情境實測（zsh/bash × 齊件/缺件）一致（教訓：**skill 內 bash snippet 必須 zsh/bash 皆安全——不用裸 glob**）。互審加碼三修：①**同檔並行防撞**——r1 抓到 /tmp 指標檔會被第二審覆寫、round 2+ resume 錯 thread；首修 check-then-set 被 r2 MAINTAIN（TOCTOU 競態），終版 `mkdir $KEY.lock` 原子取鎖、敗方即停、持鎖方才發布指標、finalize 收指標＋釋鎖。②**仲裁卷宗補作者側**——原 Step 7 承諾「留存歧見全文」但 renderer 只抽 verdict、作者方回應從未落盤（人裁拿殘卷）：我方逐輪訊息先落 `a<N>.txt` 再以檔案餵 codex stdin（subagent 版同）、歸檔含 a*.txt，renderer 對非 approved verdict 附「歧見全文」雙方逐輪原文附錄（缺件明示；round 1 為固定證偽 prompt 無作者檔屬設計）。③**同檔重審不混批**——歸檔前把 STATE 頂層舊檔整批 mv 進 `prev-<UTC時間戳>/` 不可變快照，頂層恆為單一現行批（hook 契約不變：只讀頂層），歷史保留不刪。審查歸檔本身即②③首航。另記一筆流程教訓：審前初判「上一版 marker 已 stale」是 `grep|head` 截斷誤讀——**宣稱前 read-back 全量，勿信截斷輸出**。發佈審查（README 錨、同 reviewer）R1 三 MAJOR 全修：④**D14 輪數完備＋最終輪裁決**——原四要件只收「任一非空 r*.txt」，rounds=N 缺中間輪、或最終輪原文非 APPROVED 也能湊齊證據；D14 逐輪驗 r1..rN 非空＋approved 時終輪 `## Verdict` 原文必為 APPROVED（r4 追修：rounds 強制 1–5 且取自獨立行 marker——rounds=0 原可讓整段靜默跳過，迴歸 M21/M21b）。⑤**marker 獨立行教義**——content_sha 原為「行含 marker 即整行剝除」，在 marker 行前塞字可逃出指紋而 marker 照樣 valid；改為與 sentinel 同教義：獨立一行才算 marker（辨識與剝除同一規則集），D1/D8/D12/D13 的 grep 同步錨定行首尾。⑥**D10b 專案級 codex 設定偵測**——codex 設定優先序中專案層（被審 repo 的 `.codex/config.toml`）覆蓋使用者層，校準背書只及使用者層宣告、無需蓄意即失效；自被審檔向上探索（$HOME 除外），命中即 fail-closed 需簽核。Gate 3 隔離 HOME 實測 PASS 另修二：probe 登入判定改 exit code（字串比對把 "Not logged in" 誤判為已登入）；selftest 加 trap 清 /tmp 沙盒。迴歸 M18–M20，套件 67→74 案例全綠。
